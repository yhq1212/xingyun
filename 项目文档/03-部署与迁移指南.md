# 部署与迁移指南（换电脑直接拷贝继续干）

> 适用：把整个 `AriaNg-1.3.15-AllInOne` 目录拷贝到另一台 Windows 电脑后，如何跑起来 / 继续开发。
> 交付物名称：**WuLiao**（基于 AriaNg 前端二次开发，内置「循环下载」功能）；下文中的 *AriaNg* 指其底层前端框架。

---

## 0. 快速开始（最终用户 / 交付场景）

1. 把 **`WuLiao.exe`** 拷到任意位置（或连同整个目录一起交付）。
2. **双击 `WuLiao.exe`**。
3. 首次会自动把内置资源解压到 `<WuLiao.exe 同目录>/_wuliao_runtime/`（含 `aria2c.exe`、`loop-helper/`、`index.html`），并拉起：
   - aria2 RPC：`http://localhost:6800`
   - 辅助服务（loop-helper）：`http://localhost:18888`
   - 管理界面：`http://localhost:6688`（自动打开默认浏览器）
4. **界面默认是英文**。如需中文：进入「AriaNg 设置 → 语言」改为「简体中文」并保存（必要时 `Ctrl+F5` 强刷）。
5. 左侧「Loop / 循环下载」面板配置链接与次数，点「开始」即可。
6. **关闭 EXE 弹出的黑色窗口 = 停止所有服务**（aria2 与辅助服务一并退出）；下载文件在 `_wuliao_runtime/downloads`。

> 解压只需一次；之后启动会复用 `_wuliao_runtime`，不会重复解压。

## 1. 环境要求

| 组件 | 是否必须 | 说明 |
| --- | --- | --- |
| `WuLiao.exe` | **必须（最终用户）** | 单文件交付物，已内置 Node 运行时 + aria2c + loop-helper，**对方电脑无需安装任何东西** |

> 校验 Node（仅开发用）：`node --version` 应能输出版本号。

## 2. 单文件 EXE 交付（最终用户 / 交付）

`WuLiao.exe` 是把 **aria2c + loop-helper + AriaNg 前端 + Node 运行时** 打包成的单个可执行文件，由 `build/launcher.js` 作为启动器编译而来。它的运行行为：

- **自身内置 Node 运行时**（pkg 打包，约 Node 18），对方电脑不需要预装 Node；
- 首次启动把资源解压到 `<同目录>/_wuliao_runtime/`：
  - `aria2c.exe` —— 实际下载引擎（RPC 端口 6800）
  - `loop-helper/server.js` —— 循环引擎 + 删文件 + 关机 + REST（端口 18888，进程内加载）
  - `index.html` —— AriaNg 单文件前端
  - `downloads/` —— 默认下载目录
- 内置一个微型 HTTP 服务托管界面（端口 **6688**），并自动打开浏览器；
- 若 6688 / 6800 / 18888 中某端口已被占用，EXE 会**跳过已运行的服务**（不重复拉起），直接打开界面；
- **关闭 EXE 窗口即停止所有服务**（aria2 子进程与进程内的辅助服务一并退出）。

> 源码模式下（见 §3）仍可用 `start.bat` 一键启动，等价于 EXE 的“解压 + 拉起”过程，区别在于不打包、需要本机已装 Node。

## 3. 源码 / 开发运行（改过代码时）

当你修改了 `AriaNg-master/src` 或 `loop-helper/server.js` 后，不能直接用旧的 `index.html`，需要走构建流程（见 §5）再运行。开发期可用 `start.bat` 一键启动：

1. 检查 Node 是否可用；
2. 创建 `downloads/` 下载目录；
3. 启动 aria2（开启 RPC，端口 6800）；
4. 启动 `loop-helper`（端口 18888）；
5. 打开根目录 `index.html`（AriaNg）。

启动后确认：
- aria2：`http://localhost:6800/jsonrpc` 可连通；
- helper：`http://localhost:18888/api/health` 返回 `{"ok":true,...}`。

在 AriaNg 左侧应能看到 **Loop / 循环下载** 入口；首次使用请到「AriaNg 设置」确认
“Loop Download Helper URL = http://localhost:18888”。

## 4. 手动启动（排查问题时用）

```bat
:: 1) 启动 aria2（RPC 开、无密钥示例）
aria2-1.37.0-win-64bit-build1\aria2c.exe ^
  --enable-rpc --rpc-listen-all=false --rpc-listen-port=6800 ^
  --rpc-allow-origin-all --rpc-secret= --dir="%cd%\downloads" --continue=true

:: 2) 启动辅助服务（可加环境变量）
set HELPER_PORT=18888
set ARIA2_HOST=127.0.0.1
set ARIA2_PORT=6800
set ALLOWED_ROOTS=D:\your\downloads    :: 强烈建议配置删除白名单
cd loop-helper
node server.js
```

环境变量说明：
- `HELPER_PORT`：helper 监听端口（默认 18888）
- `ARIA2_HOST` / `ARIA2_PORT`：aria2 RPC 地址（默认 127.0.0.1:6800）
- `ARIA2_SECRET`：若 aria2 启用了 `--rpc-secret`，在此填写
- `ALLOWED_ROOTS`：逗号分隔的允许删除根目录（强烈建议配置，防误删）
- `PER_DOWNLOAD_TIMEOUT`：单次下载超时毫秒（0=不限）

## 5. 修改源码后如何重新构建

根目录的 `index.html` 是**预编译好的单文件包**，不会自动包含 `AriaNg-master/src` 的改动。改完源码后必须构建。

### 5.1 重新构建 AriaNg 前端（index.html）

```bat
cd AriaNg-master
npm install            :: 安装 gulp 等构建依赖（首次较慢）
gulp clean build-bundle   :: 生成 All-In-One 版本
```

构建产物在 `AriaNg-master/dist/`。将 `dist/index.html` 复制并**覆盖**项目根目录的 `index.html`。

> 提示：仅开发 `loop-helper` 时无需构建 AriaNg；只有改了 `AriaNg-master/src` 才需要。反之，改了 `loop-helper/server.js` 只需**重启辅助服务**（重开 `WuLiao.exe` 或重跑 `start.bat`），无需构建。

> ⚠️ **新增 JS 文件必须登记**：AriaNg 用 `gulp-useref`，只会打包 `src/index.html` 里显式 `<script src="...">` 引用的 JS。
> 如果你新增了控制器/服务（如 `scripts/controllers/xxx.js`），**必须在 `src/index.html` 的 `<!-- build:js js/aria-ng.min.js -->` 块内补一行 `<script src="scripts/controllers/xxx.js"></script>`**，否则该文件不会进 bundle，页面会出现“`{{ }}` 原样显示、控件点不动”的典型症状。视图 `src/views/*.html` 会被自动收集，无需登记。

### 5.2 重新打包单文件 EXE（WuLiao.exe）

前端或辅助服务改动后，需重新生成 `index.html` 与 `server.js`，再重打包 EXE：

1. 先按 §5.1 重新构建 `index.html`（覆盖根目录 `index.html`）；
2. 把最新产物同步进 `build/res/`：
   - `build/res/index.html` ← 根目录 `index.html`
   - `build/res/aria2c.exe` ← `aria2-1.37.0-win-64bit-build1/aria2c.exe`
   - `build/res/loop-helper/*` ← `loop-helper/*`（server.js 等）
3. 用 pkg 打包：

   ```bat
   cd build
   npx --yes pkg@5.8.1 launcher.js --targets node18-win-x64 --assets "res/**/*" --output WuLiao.exe
   ```

   产物 `build/WuLiao.exe` 拷到项目根目录即可交付。

> ⚠️ **打包关键坑（务必先看）**：pkg 并不是用你机器上/项目里的普通 node，而是需要它在 GitHub 上发布的一个**「补丁版 Node 运行时」**二进制（`node-v18.5.0-win-x64`，约 64MB，位于 `vercel/pkg-fetch` 的 releases）。
> - 这个补丁版二进制**带 SHA256 校验**：pkg 会比对哈希，不符就删掉重新下载。所以**绝对不能用官方 node.exe（含你项目里 `node-v24.22.0/node.exe`）替换缓存文件**——替换了也会被判定哈希不符、重新去 GitHub 拉。
> - **境内镜像（腾讯云、npmmirror、ghproxy 等）都不托管这个补丁版二进制**，因此「用腾讯云镜像加速打包」这条路客观上走不通（已逐一实测：这些镜像的 `github-release` / `binaries` 路径对该文件均返回失败）。
> - 直连 GitHub 通常可达但较慢（几十 MB，可能要几分钟）；个别网络下会中途停滞，重跑即可。
> - **零下载兜底方案**：若联网拉取不便，可直接用项目内 `node-v24.22.0/node.exe` + Windows 自带的 `IExpress`（`sfxmake.exe`）把 `node.exe` + `launcher.js` + `aria2c.exe` + `index.html` + `loop-helper/` 打成自解压单文件 EXE（命令 `iexpress /N /Q xxx.sed`），全程不联网。代价是每次启动会解压到临时目录（约百 MB，几秒），运行时数据应固定写到 `%LOCALAPPDATA%\WuLiao` 而非随解压目录，避免丢失。

- `build/launcher.js` 是启动器入口：负责解压资源、拉起 aria2、在进程内加载 loop-helper，并内置微型 HTTP 服务托管界面（端口 6688）。
- 若将来需要指定 Node 版本或目标平台，调整 `--targets`（如 `node18-win-x64` / `node18-linux-x64` / `node18-macos-x64`）。

## 7. 常见问题（FAQ）

**Q1：界面里看不到“循环下载”入口？**
A：根 `index.html` 是旧包，未含新面板。改过源码需按 §5.1 重新构建并覆盖；若没改源码，确认用的是本项目根 `index.html` 且辅助服务已启动（用 `WuLiao.exe` 或 `start.bat` 启动）。

**Q2：点“开始”后提示 helper 地址未配置？**
A：到「AriaNg 设置」填写 `http://localhost:18888`，或用 `loop-helper` 自带的 `loop-config.json` 直接 POST。

**Q3：以 `file://` 打开 AriaNg 调不通 helper（跨域）？**
A：用 `start.bat` 以 `file://` 打开时，helper 已做 Origin 反射兼容 `null` 源，多数浏览器可用；若被拦，用一个本地静态服务器打开 AriaNg（如 `npx serve` 或 `python -m http.server`）。**用 `WuLiao.exe` 则界面走 `http://localhost:6688`，不存在此问题。**

**Q4：删除文件没生效 / 误删风险？**
A：正式使用前务必设置 `ALLOWED_ROOTS` 白名单；非白名单路径会被拒绝并记录日志。删除仅针对 aria2 回报的文件路径。

**Q5：关机没发生？**
A：先点“测试关机”验证命令；确认 `endAction` 设置正确且（默认）循环成功完成；`endActionOnlyOnSuccess=true` 时失败不会关机。

**Q6：关掉浏览器循环还在跑吗？**
A：在跑。引擎在本地 `loop-helper`，与浏览器无关；可在面板或 `POST /api/loop/stop` 停止。注意：关闭的是「浏览器」循环照跑；**关闭 `WuLiao.exe` 窗口会连辅助服务一起停掉**。

**Q7：为什么跑满我设置的次数就停了？**
A：这是正常行为——「第 3 步」里设定的次数就是上限。想一直跑，把次数填 `0`，或点一键预设「一直跑」。

**Q8：我一次想下多个文件 / 多个链接怎么办？**
A：把多个链接**一行一个**粘进第 1 步，下面会冒出「多个链接怎么处理」四选一：
- **每个链接独立循环（下完立即重下）**：每个链接各自反复下载，互不等待（**默认**）。适合大小文件混合——小文件不用等最慢的大文件；
- **每个链接都下载（一个一个来）**：顺序下载，一轮内各下一次，一轮全部完成后才进入下一轮；
- **每个链接都下载（同时下载，更快）**：同一轮内同时下载；
- **当作同一个文件的多个来源（镜像）**：只下一个文件，多个链接互为备用来源。

独立循环的"次数"指每个链接各自下载几遍（总次数 = 链接数 × 次数）；其余三种一轮结束后统一删除该轮文件再进入下一轮。对应配置 `multiMode`（`independent` / `separate` / `concurrent` / `mirror`）。

**Q9：删除没生效，日志里有 `delete-skipped`？**
A：说明你在「安全设置」里配了白名单，而下载目录不在白名单内。把该目录加进白名单即可（留空表示不限制）。白名单存在 `loop-helper/helper-settings.json`。

**Q10：面板文案想改 / 加别的语言？**
A：面板文案全部走 `translate` key（key 就是英文原文），中文在 `AriaNg-master/src/langs/zh_Hans.txt` 的 `[global]` 段。改完**必须重新构建**（§5.1）才会生效；其它语言没配的 key 会自动回退成英文。**带参数的词条占位符必须写双花括号 `{{name}}`**（如 `Round {{current}}=第 {{current}} 次`），写单花括号 `{name}` 不会替换、页面会原样显示。

**Q11：日志能留档吗？**
A：运行日志右上角有 `TXT` / `CSV` 导出按钮，CSV 带 UTF-8 BOM，可直接用 Excel 打开。

**Q12：结束动作能跑我自己的脚本吗？**
A：「更多设置」→「全部结束后要做什么」选「执行外部脚本」，填脚本路径（`.bat/.cmd/.sh/.exe`）和可选参数。脚本工作目录为脚本所在目录，超时 5 分钟。

**Q13：循环次数 / 历史会随重启丢失吗？**
A：不会。全局「已完成轮次」存在 `loop-helper/loop-state.json`，**辅助服务重启后计数继续累加**；运行历史存在 `loop-helper/loop-history.json`（最近 100 条）。两者都是本地文件。注意：持久化的是「已完成轮次」计数，正在下载的半成品任务不会断点续传。

**Q14：运行历史面板在哪？能清空吗？**
A：面板右栏「运行历史」卡片，展示统计卡片（总运行次数 / 总轮次 / 成功 / 失败 / 总下载量 / 总耗时）与每条记录。点「清空历史」只清历史；要连文件、计数、日志一起清，用状态卡右侧的「清空全部」（见 Q15）。

**Q15：点「清空全部」报 `not found`，或新加的功能没生效？**
A：都是**运行中的还是旧版程序**：
- 改了 `loop-helper/server.js` → 必须重启辅助服务（重开 `WuLiao.exe` / 任务管理器结束 `WuLiao` 进程后再双击，或重跑 `start.bat`）；
- 改了 `AriaNg-master/src` → 必须重新构建并覆盖根 `index.html`（§5.1），且浏览器 **Ctrl+F5** 强刷；若交付 EXE，还需按 §5.2 重新打包。
`loop-helper` 是常驻进程，改完代码不重启不会热加载；`index.html` 是预编译包，不重建不会包含新前端。

**Q16：界面是英文，想要中文？**
A：默认语言为英文。到「AriaNg 设置 → 语言」选择「简体中文」并保存，必要时 `Ctrl+F5` 强刷。若仍显示英文，多为浏览器缓存了旧语言设置（`localStorage` 中的 `AriaNg.Language.*`），清掉站点数据或强刷即可。

**Q17：`WuLiao.exe` 是什么？下载的文件去哪了？**
A：它是把 aria2c + loop-helper + AriaNg 前端 + Node 运行时打包成的单文件，双击即用、对方无需安装 Node。关闭它的窗口会停止 aria2 与辅助服务；下载文件在 `<WuLiao.exe 同目录>/_wuliao_runtime/downloads`。

**Q18：反复下载把我家/公司网速拉满了，怎么办？**
A：用「循环下载」面板里的**「局域网避让」**（位于「更多设置」与「安全设置」之间的折叠区）：
- 先勾选「启用局域网避让」；
- 三选一：**① 等待其他设备离线后再下载（默认推荐）**——检测到同网段有其他设备在线就暂停，对方离线后自动恢复；**② 限速下载**——对方在线时给下载限速（默认 `1M`，可改，如 `500K`），没人时满速；**③ 直接下载（仅记录）**——不做避让，只在状态卡显示“N 台其他设备在线”。
- 还可设「检测间隔（秒）」与点「立即扫描」手动测一次（返回发现的设备 IP/MAC）。
原理是 ping 整个子网 + 读 ARP 表，纯本地零依赖；探测失败会自动放行（fail-open），不会卡住下载。状态卡在运行时也会实时显示检测到的其他设备数量。

## 8. 换电脑最小步骤（速记）

最终用户：
1. 拷贝 `WuLiao.exe`（或整个目录）；
2. **双击 `WuLiao.exe`** → 自动解压、起服务、开浏览器；
3. （可选）设置里把语言改为简体中文；
4. 进入「循环下载」面板配置并“开始”。

开发/继续改源码：
1. 装 Node.js；
